# 小小识字家：私密同步版

为手机和 iPad 设计的汉字闪卡。使用 ChatGPT 登录，字库通过私密数据库在同一账号的设备之间同步。

## 功能

- 多字库、Excel / CSV / JSON 导入与 JSON 备份。
- 单字和真实词语每轮洗牌，全部出现后才开始下一轮。
- 字库新增、重命名和删除自动同步，15 秒检查一次云端变化。
- 同时编辑使用版本检查和三方合并；冲突内容保留为独立字库。
- 断网修改保存在当前设备；联网或返回页面时重试。
- 生词标记和学习轮次留在各设备，本版本只同步字库。

## 隐私与部署

网页使用 Sites 的私密访问控制和 ChatGPT 登录。服务端从受信任的登录身份读取账号 ID，每次数据库读写都限定该账号。客户端不能指定其他用户 ID。

数据库中保存字库，GitHub 仓库只保存源代码。没有任何云端密钥需要放入前端代码。

`app/route.ts` 提供登录保护后的 HTML，`app/api/sync/route.ts` 实现账号隔离和版本检查，`db/schema.ts` 与 `drizzle/` 管理数据库结构。`public/sync-core.js` 为三方合并逻辑。

## 本地开发

需要 Node.js 24。

```sh
npm ci
npm test
npm run dev
```

本地开发使用 Sites starter 的模拟身份；生产站点的身份由托管平台提供。数据库需要先生成并应用迁移，生产迁移通过 Sites 发布流程执行。

```sh
npm run db:generate
npm run build
```

开发数据库和生产数据库相互隔离。不要把 `.wrangler`、`.env`、浏览器缓存或个人字库备份提交到公开仓库。

## 旧字库迁移

旧本地 HTML 的浏览器存储无法由新网址直接访问。首次在新网址登录后，导入原有 Excel / CSV，或导入旧版导出的 JSON。之后其他设备登录同一账号即可读取，无需重复导入。
